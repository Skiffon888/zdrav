# Здравый смысл

Информационный прототип навигатора для жителей ЛНР по вопросам планирования семьи, беременности и поддержки родителей. Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий без README и `.gitignore`.
2. Выполните в папке проекта команды ниже, заменив адрес репозитория:

```bash
git init
git branch -M main
git add .
git commit -m "Prepare family support navigator"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

3. Откройте `Settings` → `Pages` в репозитории.
4. В разделе `Build and deployment` выберите источник `GitHub Actions`.
5. Дождитесь завершения workflow `Publish GitHub Pages` во вкладке `Actions`.

Сайт будет доступен по адресу `https://USERNAME.github.io/REPOSITORY/`. Последующие изменения публикуются автоматически после отправки в ветку `main`.

Файл `.gitignore` разрешает добавлять в репозиторий только файлы публичного сайта. Интервью, презентации, исследования и исходный референс не попадут в GitHub при выполнении `git add .`.

## Что работает

- Выбор жизненной ситуации и пошаговый маршрут.
- Каталог с поиском, фильтрами, карточками и подробными инструкциями.
- Ссылки на Госуслуги и СФР, печать инструкции, адаптивное мобильное меню.
- Без регистрации, аналитики, отправки форм и хранения персональных данных.
- Ежедневное серверное обновление анонсов и тематических материалов через DeepSeek по официальным открытым источникам.
- Дополнительные ссылки на «Так здорово» (портал Минздрава России), «ПроДокторов» (независимый справочник врачей) и n101.ru (сторонняя экосистема проектов для семьи). Каталог помечает тип источника и не подтверждает доступность сторонних услуг в ЛНР.

## Автоматическое наполнение

Скрипт `scripts/generate-content.mjs` получает открытые материалы Минздрава ЛНР, СФР, Минтруда и два раздела портала «Так здорово», передаёт модели `deepseek-flash` текущую дату по Москве и региональный контекст ЛНР, проверяет JSON и сохраняет только готовый публичный контент в `data/generated-content.json`. Источник по диспансеризации может содержать сведения за 2025 год; модель получает запрет переносить старые условия на текущую дату. Автоматическая проверка URL и формата не гарантирует фактическую точность текста: перед распространением нужно сверять вывод с первоисточником. «ПроДокторов» и n101.ru представлены только как ссылки в каталоге: сведения о специалистах, услугах и медицинские советы с них автоматически не собираются. API-ключ никогда не передаётся в браузер и не попадает в файлы сайта.

Для GitHub Pages создайте в `Settings` → `Secrets and variables` → `Actions` секрет `DEEPSEEK_API_KEY`. Ранее опубликованный в переписке ключ следует отозвать и заменить новым. Workflow обновляет материалы ежедневно в 05:17 МСК, при ручном запуске и при публикации. Если API или источники недоступны, сайт продолжает публиковаться, но вчерашний дайджест не отображается как сегодняшний. При отсутствии секрета остаётся статический каталог.

Для локального обновления задайте переменную окружения `DEEPSEEK_API_KEY` и выполните `node scripts/generate-content.mjs`. Модель можно переопределить переменной `DEEPSEEK_MODEL`.

## Статус информации

Контент подготовлен по паспорту проекта, SWOT-анализу, интервью и обзору региональных мер в этой папке. Это не официальный сайт ведомства и не медицинская консультация. Адреса, телефоны, графики, конкретные региональные выплаты и наличие услуг в ЛНР исходными материалами не подтверждены, поэтому они не выдуманы. Примеры других регионов не выдаются за действующие меры ЛНР. Перед публичным запуском нужен ответственный за проверку данных, утверждённый каталог организаций и регулярное обновление ссылок и условий.

Для изменения статического каталога и маршрутов редактируйте массив `topics` и объект `routes` в `app.js`. Лента новостей загружается с сайта Минздрава ЛНР, а ежедневный дайджест — из `data/generated-content.json`, если он подготовлен сегодня по московскому времени.

Оформление первого экрана основано на предоставленном файле `Сайт 3.jpg`. Из него используются фрагменты изображения как иллюстрации; встроенные в макет значки воспроизведения не означают наличие видео на сайте. Карточки ведут в каталог, а не к видеозаписям.
